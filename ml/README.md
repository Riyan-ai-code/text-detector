# ML Core Modules

This directory manages training, inference, and model configurations for TruthLens AI:

- `text/`: DeBERTa-v3 / RoBERTa / BERT fine-tuning pipelines and XGBoost stylometric ensemble.
- `plagiarism/`: BGE dense embeddings and Cross-Encoder reranker.
- `audio/`: Wav2Vec2 / Librosa acoustic feature extractors.
- `evaluation/`: Benchmark datasets, confusion matrix generators, and adversarial robustness testers.
